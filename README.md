# Silent Games

**Silent Games** is an independent mobile game developer creating simple, satisfying, and easy-to-play puzzle games.

Silent Games는 간단한 조작, 직관적인 규칙, 그리고 만족스러운 플레이 경험을 중심으로 모바일 게임을 개발하는 인디 게임 개발사입니다.

---

## Games

### Block Bloom

**Block Bloom** is a cozy 8×8 block puzzle where one move can set off bomb chains and full-board laser wipes.

Drag and drop blocks, clear lines, and trigger satisfying special-block chain reactions. No tutorial, no Wi-Fi needed.

**Block Bloom**은 한 수로 폭탄 연쇄와 전체 클리어 레이저가 터지는 아늑한 8×8 블록 퍼즐입니다.

블록을 끌어다 놓아 줄을 지우고, 특수 블록의 시원한 연쇄 반응을 터뜨리세요. 튜토리얼도, 와이파이도 필요 없습니다.

*Coming soon on Android.*

---

### Outarrow: Escape Puzzle

**Outarrow** is a simple but tricky arrow escape puzzle game.

Tap arrows in the right order and clear the board.  
Each arrow moves in its own direction, but some arrows are blocked by others.  
Think carefully, find the best move, and free every arrow.

**Outarrow**는 간단하지만 은근히 머리를 쓰게 되는 화살표 탈출 퍼즐 게임입니다.

화살표를 올바른 순서로 눌러 보드 위의 모든 화살표를 탈출시키세요.  
각 화살표는 정해진 방향으로 움직이지만, 다른 화살표에 막혀 바로 움직일 수 없는 경우도 있습니다.
